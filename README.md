# 🐍 DSA-Python

My journey of learning **Data Structures and Algorithms (DSA) using Python**.

This repository contains my solutions to DSA problems, primarily from **LeetCode**. I'm building this repository to strengthen my problem-solving abilities, understand core data structures and algorithms, improve coding efficiency, and prepare for technical interviews.

I organize my solutions topic-wise to maintain a structured learning path.

| Topic | Concepts |

| **Arrays** | Traversal, manipulation, reversing, searching, basic array problems |
| **Greedy** | Greedy strategies and optimization problems |
| **Heaps** | Heaps, Priority Queues |
| **Math** | Mathematical problems and number theory |
| **Pandas** | Data manipulation, filtering, grouping, and operations |
| **Strings** | String manipulation and problem-solving |
| **Trees** | Tree-based problems and related data structures |
